# SkillSwap - Projeto Integrador

Repositório do projeto SkillSwap. Os quatro PDFs da disciplina foram adotados como referências para a proposta, a arquitetura Angular e a interface com Angular Material.

## Estado atual

O repositório contém a documentação inicial e os materiais de apoio. Ainda não há aplicação Angular, backend, banco de dados ou comandos de execução e testes configurados.

## Documentação

- [Diretrizes do projeto](docs/diretrizes-projeto.md): síntese dos materiais, critérios de aceite e sequência de continuidade.
- [PDFs de referência](docs/referencias/README.md): documentos originais e finalidade de cada um.
- [Orientações para agentes](AGENTS.md): contexto persistente para futuras alterações.

## Continuidade

O próximo passo é definir o problema atendido pelo SkillSwap, seu público e de quatro a seis funcionalidades principais. Depois, registrar a escolha de versões e arquitetura, iniciar a aplicação e construir uma tela de cadastro do domínio com Angular Material.

As entidades usadas nos PDFs são exemplos didáticos. As funcionalidades e regras de negócio do SkillSwap ainda precisam ser definidas com a equipe.

## Versionamento

Organizar as alterações em commits por objetivo, com mensagens no formato `docs:`, `feat:`, `fix:`, `test:`, `refactor:` ou `chore:`. Antes de cada commit, revisar os arquivos incluídos e executar as verificações disponíveis para o tipo de alteração.
